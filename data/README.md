# Datasets

All files are generated by `make_assignment_2_data.py` in the course repository
(assignment 1 data predates it). That script is the regeneration path and records the
seeds; the committed files are the source of truth for the graded answers.

## Assignment 1

| File | Contents |
| --- | --- |
| `california_housing_features.parquet` | 20,640 districts, 8 features |
| `california_housing_target.parquet` | median house value per district, in units of $100,000 |

California housing dataset, derived from the 1990 U.S. census. Distributed with
scikit-learn; originally from Pace and Barry (1997), *Sparse spatial autoregressions*,
Statistics and Probability Letters 33, 291-297.

### Provenance

- **`california_housing_anomalies.parquet`** is built from
  `california_housing_features.parquet`. Districts with any feature beyond 5 standard
  deviations are removed, then 100 synthetic rows are added. Each synthetic row is a
  real district shifted along the three lowest-variance principal directions, with
  every feature kept inside |z| <= 5. The features are individually plausible; the
  combination is not, which is what the PCA exercise detects.
- **MovieLens**: the `ml-latest-small` dataset from GroupLens, filtered to movies with
  more than 100 ratings and users with at least 5 of those. Cite as: F. M. Harper and
  J. A. Konstan (2015), *The MovieLens Datasets: History and Context*, ACM Transactions
  on Interactive Intelligent Systems 5, 4, Article 19.
  See <https://grouplens.org/datasets/movielens/> for the usage terms.
- **MNIST**: a balanced subset (first 500 per digit for training, first 100 per digit
  for testing, in canonical file order). Y. LeCun, C. Cortes and C. J. C. Burges,
  *The MNIST database of handwritten digits*.
- **`toy_two_moons.parquet`** and both `.npz` files are generated with numpy from fixed
  seeds recorded in `make_assignment_2_data.py`.
